## 방법

1. `data.sec.gov/submissions/CIK##########.json`으로 각사 10-Q 식별
2. 원문 HTML 직접 다운로드 후 텍스트 변환
3. Item 2(MD&A) 구간 및 재무제표 주석 추출
4. 기재값 그대로 인용, 비율·합계는 원문 수치로 계산

## 한계

10-Q는 고객별 매출을 원칙적으로 공시하지 않습니다. Microsoft의 OpenAI 매출은 지분법 피투자자 관련당사자 공시 의무 덕분에 드러난 예외이며, Alphabet과 Amazon의 AI랩 의존도는 계약 금액 기반 추정입니다. 리포트는 공시 사실과 추정을 등급으로 분리해 표기했습니다.
